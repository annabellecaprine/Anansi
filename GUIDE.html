Platform Export Guides

Learn how to export your Anansi project for various AI platforms.

ST
SillyTavern / Agnaistic

Best for full V2 Character Card support.
  1. Click the Export button in the Top Bar (right side).
  2. Select V2 Character Card (.png).
  3. Save the PNG image to your device.
  4. Import this PNG directly into SillyTavern or Agnaistic. Anansi scripts and lore are embedded in the card metadata.

JAI
JanitorAI

Recommended Method: Manual Script Build
  1. Open the Scripts panel in Anansi.
  2. Click the Export (zip) icon in the header or download individual scripts.
  3. Go to JanitorAI and create a new Character.
  4. Fill in the Name and Description manually.
  5. Copy the content of your Anansi logic scripts (e.g., main.js or sys_pulse.js output) and paste them into the Scenario or First Message fields as required by your prompt strategy.
  6. Tip: JAI may strip embedded scripts from V2 cards, so manually pasting the text/code ensures persistence.

CH
Chub.ai

Lorebook Sharing
  1. Open the Lorebook panel in Anansi.
  2. Click the Export button in the footer.
  3. Choose JSON (Standard).
  4. On Chub.ai, use the "Import Lorebook" feature and select your JSON file.
